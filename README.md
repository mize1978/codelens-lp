## What is this?

This is the **landing page for CodeLensAI** — a product built around a single idea:

> **Repository Intelligence** — reviewing code shouldn't end at the review.
> It should be understood, remembered, and grown over time.

Most AI review tools give you a score and stop. CodeLensAI treats each review as the
**entrance** to a repository's knowledge: it reads the code, scores it, explains *why*,
remembers what it learned, and tracks how the repository grows.

```
Read → Understand → Remember → Grow
```

## Proof, not just pitch

CodeLensAI reviewed [`mize1978/rewardme`](https://github.com/mize1978) **5 times**.
The repository actually improved: overall **49 → 66 (+17)**, security **45 → 70 (+25)** —
the biggest gain. This isn't a result, it's a **trajectory**.

→ [See the score trend](https://mize1978.github.io/codelens-lp/rewardme-score-trend.html)
